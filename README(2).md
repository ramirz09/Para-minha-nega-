# Para minha nega ❤️

Uma página romântica em tons pastel, com galeria de fotos e uma carta pessoal.

## Arquivos
- `index.html`: estrutura principal da página.
- `styles.css`: cores, layout, responsividade e animações.
- `script.js`: carrega a galeria e a carta a partir do JSON, cria os corações e controla a ampliação das fotos.
- `data.json`: textos da carta, legendas e caminhos das imagens.
- `assets/`: fotos usadas na galeria.

## Visualizar localmente
Como o site carrega `data.json` com `fetch`, abra por um servidor local (por exemplo, Live Server no VS Code), e não diretamente por `file://`.

## Publicar no GitHub Pages
1. Envie todos os arquivos e a pasta `assets` para a raiz do repositório.
2. Abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
5. Aguarde o GitHub publicar o endereço do site.

> Mantenha a estrutura de pastas e os nomes dos arquivos para que as fotos e os textos carreguem corretamente.
